# Precision Baking

An AI-powered ingredient conversion tool for precise baking.

## Features

- Convert common baking measurements to precise gram weights
- Natural language input processing
- Recipe scaling functionality
- Recent conversion history
- Intelligent ingredient matching with fuzzy search
- Dark/light theme support
- Mobile-responsive design

## Technology Stack

- React
- TypeScript
- Tailwind CSS
- Fuse.js for fuzzy searching

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm start
   ```

## Usage Examples

- Convert standard measurements: "1 cup of flour" → 120g
- Scale recipes up or down with the scaling tool
- Use natural language input: "2.5 tbsp of peanut butter"
- View your recent conversions for quick reference
